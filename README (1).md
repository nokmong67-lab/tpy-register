# ทะเบียนคุมและติดตามการชำระเงิน — โรงพยาบาลตาพระยา

ระบบทะเบียนคุมหนังสือเรียกเก็บ/แจ้งโอน ทำงานเป็นหน้าเว็บไฟล์เดียว (`index.html`) บน GitHub Pages และเก็บข้อมูลใน Google Sheets ผ่าน Google Apps Script

## ขั้นตอนงาน
1. **รับหนังสือ** บันทึกหนังสือเรียกเก็บ / แจ้งโอน
2. **ตรวจสอบ** พร้อมดาวน์โหลดบันทึกข้อความ (.docx)
3. **ทำหนังสือ** แจ้งโอน หรือส่งใบเสร็จ (ภายนอก/ภายใน) ดาวน์โหลดเป็น .docx
4. **ติดตามใบเสร็จ** ภายใน 30 วัน

มีแดชบอร์ดสรุปยอดเรียกเก็บ/ยอดโอนรายหน่วยบริการ ล็อกอินพร้อมสิทธิ์รายคนต่อขั้นตอน เลือกสีธีมได้ และแสดงวันที่เป็น พ.ศ.

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (อัปโหลดขึ้น GitHub) |
| `Code.gs` | ตัวเก็บข้อมูล วางใน Apps Script ของ Google Sheet (**ไม่ต้องอัปโหลดขึ้น GitHub**) |

## ติดตั้ง
### 1) Google Sheets + Apps Script
1. สร้างสเปรดชีตใหม่ → **ส่วนขยาย → Apps Script**
2. วางโค้ดจาก `Code.gs` และแก้ `var API_KEY = '...'` เป็นรหัสลับของหน่วยงาน
3. **Deploy → New deployment → Web app** · Execute as: **Me** · Who has access: **Anyone**
4. คัดลอก Web app URL (ลงท้าย `/exec`)

แก้ `Code.gs` ภายหลัง ต้อง Deploy → Manage deployments → New version

### 2) GitHub Pages
1. สร้าง repository (Public) อัปโหลด `index.html` และ `README.md`
2. **Settings → Pages → Deploy from a branch → `main` / root**
3. เปิด `https://<ชื่อ-github>.github.io/<ชื่อ-repo>/`

### 3) ใช้งานครั้งแรก
1. กรอก URL ของ Web app และรหัสลับ ในหน้าต่างเชื่อมต่อ (ระบบจำไว้ในเบราว์เซอร์)
2. ตั้งซูเปอร์แอดมินคนแรก
3. เพิ่มเจ้าหน้าที่ที่เมนู **ผู้ใช้งานและสิทธิ์**

## ความปลอดภัย
- **ห้ามใส่ `API_KEY` ลงใน GitHub** แจกรหัสให้เฉพาะเจ้าหน้าที่ที่เกี่ยวข้อง
- ผู้มีรหัสลับเขียนข้อมูลผ่านสคริปต์ได้ทั้งหมด สิทธิ์รายคนในแอปควบคุมเฉพาะการใช้ผ่านหน้าเว็บ
- รหัสผ่านผู้ใช้เก็บเป็นแฮช (PBKDF2) ไม่ควรใส่ข้อมูลผู้ป่วยรายบุคคลลงระบบ
- ถ้ารหัสรั่ว ให้เปลี่ยน `API_KEY` แล้ว Deploy เวอร์ชันใหม่

## ข้อมูล
ชีต `records`, `users`, `settings`, `agencies` เก็บข้อมูลเป็น JSON ห้ามแก้ด้วยมือ ควรทำสำเนาสเปรดชีตสำรองเป็นระยะ ระบบซิงก์ข้อมูลทุก ~6 วินาที ถ้าสองคนแก้รายการเดียวกันพร้อมกัน ฉบับที่บันทึกทีหลังจะทับ

## แก้ปัญหา
- **เชื่อมต่อไม่สำเร็จ** ตรวจว่า Deploy เป็น Anyone และ URL ลงท้าย `/exec`
- **รหัสลับไม่ถูกต้อง** ต้องตรงกับ `API_KEY` ใน Code.gs ทุกตัวอักษร
- **แก้ Code.gs แล้วไม่เปลี่ยน** ต้อง Deploy เป็น New version
